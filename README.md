# Excel03-Porter-Delivery-Analysis

The Porter Delivery Analysis project focuses on analyzing delivery-related data to identify operational patterns, performance trends, and factors affecting delivery operations.

## Objectives
1. Analyze delivery-related data
2. Identify important operational trends
3. Calculate relevant business metrics
4. Compare delivery performance
5. Generate actionable insights from the dataset
6. Present findings using Excel visualizations
   
## Key Analysis Areas
1. Delivery performance
2. Order-related analysis
3. Time-based analysis
4. Operational trends
5. Performance comparison
6. Business KPIs
   
## Excel Skills Used

2. Excel Formulas
3. Pivot Tables
4. Pivot Charts
5. Conditional Formatting
6. Sorting & Filtering
7. KPI Analysis
8. Data Visualization
9. Dashboard Creation
